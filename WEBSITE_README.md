# Quadnex Technologies Website

A modern, professional software house website for Quadnex Technologies featuring cutting-edge design, smooth animations, and responsive layout.

## 🚀 Features

- **Modern Design**: Clean, professional design with gradient accents and smooth animations
- **Fully Responsive**: Optimized for all devices - desktop, tablet, and mobile
- **Interactive Elements**: Animated counters, hover effects, and smooth scrolling
- **Multiple Sections**:
  - Hero section with call-to-action buttons
  - Services showcase with 6 key offerings
  - About us with company information
  - Portfolio with featured projects
  - Team members showcase
  - Contact form with validation
  - Newsletter subscription
  - Footer with quick links

## 📋 Technologies Used

- **HTML5**: Semantic markup for better SEO
- **CSS3**: Modern styling with CSS Grid, Flexbox, and animations
- **JavaScript**: Interactive features and form handling
- **Font Awesome**: Professional icons
- **Google Fonts**: Inter and Poppins font families

## 🎨 Design Features

## 🌐 How to Use

### Option 1: Direct Opening
Simply open `index.html` in a modern web browser (Chrome, Firefox, Safari, Edge)

### Option 2: Local Server
For better performance and testing, use a local server:

#### Python (Python 3)
```bash
python3 -m http.server 8000
```
Then visit: http://localhost:8000

#### Node.js (with npx)
```bash
npx http-server
```

#### PHP
```bash
php -S localhost:8000
```

## 🎯 Customization

### Colors
Edit CSS variables in `styles.css`:
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    --accent-color: #ec4899;
    /* ... other colors */
}
```

### Content
- Edit `index.html` to update text content
- Replace placeholder images with actual images
- Update contact information
- Add real project links

### Animations
- Modify animation timing in `script.js`
- Adjust CSS transitions in `styles.css`
